# File-manager window concept v1

`file-manager-window-v1.png` is an imagegen-generated UI mockup, requested by Arne
on 14 November 2026. It is not an application screenshot or a committed feature
specification. The source image remains in the generated-images archive too.

The native filter candidate is real. Saved workspaces, Places, locked destination,
action search, breadcrumbs and the integrated operation shelf in the concept are
proposals. Theme, density and accessibility must be validated through native code,
not copied pixel-for-pixel from a generated image. The prompt's use of source and
destination colours is exploratory; labels must remain sufficient without colour.

Generated using the built-in imagegen tool, not the CLI/API fallback.
Prompt brief: a realistic native Haiku Lister window, yellow title tab, compact
native controls, two equally capable source/destination panels, visible literal
filters and counts, Places and saved workspaces, a small action bank and integrated
operation shelf. Calm, discoverable, keyboard-friendly; neither an Amiga replica
nor a web dashboard. Exact visible disclaimer: `LISTER · CONCEPT MOCKUP`.
