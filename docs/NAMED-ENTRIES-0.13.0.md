# Listi 0.13.0: named copies and links

Files > More file actions offers Duplicate (Command+Shift+D) and Create symbolic
link (Command+Shift+L). Select exactly one local file, folder or symbolic link.
Duplicate proposes an unused name beside the original, preserving the extension.
Link uses the other panel's folder; choose Relative link or Absolute link explicitly.
The text field's Enter creates the default relative link. Escape/Cancel does nothing.
Invalid or existing names retain the draft. No existing entry, including a broken
symbolic link, is replaced. The system clipboard is unchanged.

Source and destination identities are snapshotted when the question opens. Later
navigation cannot redirect the job; replaced entries cause refusal. Duplicate uses
the queued recursive copier, preserving supported metadata and copying symlinks
as links. Cancellation keeps completed files and may leave a partial new directory,
never removes the original. A relative link follows a relocated common tree; an
absolute link keeps its original target path. Links use native exclusive creation,
not a shell. They neither copy nor change the target. A later moved/deleted target
can leave a broken link. No remote/archive creation, hard links, bulk duplicate,
or Show Target action is implemented in this increment.

## Identity and keyboard

The native package is now named `listi`, replacing `lister`, with compatibility
provides for the old name. Apps/Listi and the Deskbar entry keep their existing
paths. The legacy application signature and Lister_* settings names are deliberately
unchanged so preferences, places, saved searches and running-app integration survive.
No user data is migrated or deleted. Native icon art is original MIT vector artwork
in artwork/Listi.svg and artwork/Listi.hvif, reproducibly generated by
artwork/generate_icon.py and embedded through src/ListiIcon.rdef.

Function keys are unassigned, including the former F3 through F9 aliases. Use
Command+Shift+V for View, Command+Shift+C for panel Copy, Command+E/M/R/N/D
for Edit/Move/Rename/New folder/Trash, and Command+, for preferences. Command is
normally Alt, according to Haiku's keymap. Command+W retains system window-close
behavior; closing the sole main window normally exits the app, subject to pending
job and protected-draft checks. Escape cancels inline questions; Command+Q quits.

The main layout and panel maximum sizes are unbounded after layout attachment.
Showing a question must not let transient child maximum widths shrink the window.
The file panels receive spare vertical space, not the empty button-bank footer.
