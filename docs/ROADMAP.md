# Incremental roadmap

1. Local foundation: two panels, source/destination, selection, worker operations,
   native layout, preferences, reproducible packaging and native verification.
2. Native Trash/restoration, then approved portable-core migration (see design
   proposal), before further feature expansion.
3. Everyday power: seek/filter, batch rename with preview, bookmarks/hotlist,
   tabs and saved layouts, configurable command/button banks and filetypes.
4. Providers: SFTP and FTP/FTPS with secure credential storage, cancellable jobs,
   reconnect/resume, remote listing; archives with safe extraction and previews.
5. Independent listers and locked roles, compare/sync with dry-run preview,
   content search, checksums, Haiku attributes/queries and extensible commands.

Each round must deliver an installable, versioned HPKG, source, screenshots and
specific passed/unverified checks. Advanced features are goals, not promises
that version 0.1.0 already implements them.

6. Optional Tracker-like desktop shell after a separate compatibility study.
   Plan 9/9front implementation is a later independent frontend/backend, not now.
